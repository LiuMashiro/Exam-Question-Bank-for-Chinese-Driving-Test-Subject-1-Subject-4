## 一、速度限制

**★★★★★ · 约7%**

### 1.1 普通道路

```
无中心线 → 城市 30km/h  |  公路 40km/h
有中心线 → 城市 50km/h  |  公路 70km/h
```

> 口诀：无中心线城3公4，有中心线城5公7

### 1.2 特殊路段 一律 30km/h

进出非机动车道 | 铁路道口 | 急弯路 | 窄路 | 窄桥 | 掉头 | 转弯 | 下陡坡 | 能见度50m内 | 冰雪泥泞路 | 牵引故障车

### 1.3 高速公路

| 类别             | 限速    |
| ---------------- | ------- |
| 最高车速         | 120km/h |
| 最低车速         | 60km/h  |
| 小型载客汽车最高 | 120km/h |
| 其他机动车最高   | 100km/h |
| 摩托车最高       | 80km/h  |

**多车道最低速**（无标志默认值）：

| 车道数 | 最左    | 中间   | 最右   |
| ------ | ------- | ------ | ------ |
| 2车道  | 100km/h | —      | 60km/h |
| 3车道+ | 110km/h | 90km/h | 60km/h |

> 限速标志优先于通用规定。

### 1.4 高速低能见度

```
261 → 能见度<200m → 车速≤60km/h → 跟车≥100m
145 → 能见度<100m → 车速≤40km/h → 跟车≥50m
520 → 能见度<50m  → 车速≤20km/h → 尽快驶离
```

| 能见度 | 最高车速 | 跟车距离 | 灯光                          |
| ------ | -------- | -------- | ----------------------------- |
| <200m  | ≤60km/h  | ≥100m    | 雾灯 + 近光 + 示廓 + 前后位灯 |
| <100m  | ≤40km/h  | ≥50m     | 上述 + 危险报警闪光灯         |
| <50m   | ≤20km/h  | 驶离     | 上述 + 尽快驶离高速           |

### 1.5 高速跟车

- 车速 > 100km/h → 保持 **100米以上**
- 车速 ≤ 100km/h → 不得少于 **50米**

## 二、记分规则

**★★★★★ · 约8%**

> 163号令核心变化：取消2分档，新增9分档。五档为 **12 / 9 / 6 / 3 / 1**。

### 2.1 一次记 12 分

- 饮酒后驾驶机动车
- 造成致人轻伤以上或死亡事故后逃逸，尚不构成犯罪
- 使用伪造、变造的号牌 / 行驶证 / 驾驶证 / 校车标牌
- 使用其他机动车号牌、行驶证
- 驾驶校车 / 公路客运 / 旅游客运汽车超载 20% 以上
- 校车 / 中型以上客货车 / 危险品车以外车辆，在高速 / 快速路超速 50% 以上
- 代替实际驾驶人接受处罚和记分牟取经济利益
- 驾驶校车 / 公路客运 / 旅游客运 / 7座以上以外的载客汽车超载 100% 以上

### 2.2 一次记 9 分

- 驾驶与准驾车型不符的机动车
- 未悬挂号牌或故意遮挡 / 污损号牌
- 在高速公路 / 城市快速路上违法停车
- 驾驶 7 座以上载客汽车超载 50%~100%
- 未取得校车驾驶资格驾驶校车
- 连续驾驶中型以上载客汽车 / 危险品运输车超 4 小时未休息（或休息 <20分钟）

### 2.3 一次记 6 分

- 造成致人轻微伤或财产损失事故后逃逸，尚不构成犯罪
- 驾驶证被暂扣 / 扣留期间驾驶机动车
- 驾驶小型汽车在高速公路上超速 20%~50%
- 驾驶小型汽车在普通道路上超速 50% 以上
- 驾驶 7 座以下载客汽车超载 50%~100%
- 驾驶校车 / 公路客运 / 旅游客运汽车超载未达 20%
- 载货汽车超载 50% 以上
- 运载危险品未经批准 / 未按指定路线行驶
- 7 座以上载客汽车超载 20%~50%

### 2.4 一次记 3 分

- 不按规定安装号牌
- 拨打、接听手持电话等妨碍安全驾驶行为
- 遇前方排队或缓行时借道超车 / 占用对面车道 / 穿插等候车辆
- 不按规定超车、让行，或在高速 / 快速路以外的道路上逆行
- 驾驶小型汽车在普通道路上超速 20%~50%
- 小型汽车载客超载 20%~50%
- 不按规定避让校车
- 在高速公路上行驶低于最低时速
- 行经人行横道不按规定减速 / 停车 / 避让行人
- 载货汽车超载 30%~50% 或违法载客
- 连续驾驶载货汽车超 4 小时未休息（或休息 <20分钟）
- 故障停车不按规定使用灯光或设置警告标志

### 2.5 一次记 1 分

- 开车上路不系安全带
- 在高速 / 快速路以外的道路不按规定倒车 / 掉头
- 不按规定会车
- 违反禁令标志 / 禁止标线指示
- 载货汽车超载未达 30%
- 载货长宽高超过规定
- 不按规定使用灯光
- 不按规定年检

### 2.6 记分周期与满分学习

- 记分周期：**12个月**，从初次领证之日起计算
- 记满 12 分 → 扣留驾驶证，参加 7 天法规学习（小型汽车）/ 30 天（大中型客货车）
- 累积 24 分未满 36 分 → 法规考试合格后，**取得学习驾驶证明满 30 日**后预约科目三
- 累积满 36 分或 3 次以上满 12 分 → 法规考试 + 科二 + 科三
- 满分学习次数每增加一次，学习时间增加 7 天，最多 60 天

### 2.7 学法减分

- 一个记分周期内最高可减 **6 分**
- 网上学习 **3 天累计** 30 分钟考试合格 → 减 1 分
- 现场学习 1 小时考试合格 → 减 2 分
- 公益活动 1 小时 → 减 1 分
- 实习期内不得参加
- 有逃逸 / 饮酒 / 伪造 / 买卖分等记录 → 不得参加

## 三、交通信号

**★★★★★ · 约12%**

### 3.1 优先级

**交警指挥 > 信号灯 > 标志标线**

### 3.2 信号灯

| 信号         | 含义                                       |
| ------------ | ------------------------------------------ |
| 绿灯         | 准许通行                                   |
| 红灯         | 禁止通行（圆形红灯可在确保安全前提下右转） |
| 黄灯         | 已过停止线可继续，未过应停车               |
| 黄灯持续闪烁 | 注意瞭望，确认安全通过                     |
| 方向箭头红灯 | 该方向禁止通行，**不可右转**               |
| 红色叉形灯   | 禁止该车道通行                             |

> 圆形红灯右转可以（安全前提下），箭头红灯右转不可以。

### 3.3 交通标志

| 类型         | 颜色           | 作用         |
| ------------ | -------------- | ------------ |
| 警告标志     | 黄底黑边三角形 | 警告注意危险 |
| 禁令标志     | 白底红边圆形   | 禁止或限制   |
| 指示标志     | 蓝底白图案     | 指示应遵循   |
| 指路标志     | 蓝 / 绿底白字  | 传递方向地点 |
| 旅游区标志   | 棕底白字       | 旅游景点     |
| 施工安全标志 | 橙底           | 施工区域     |
| 辅助标志     | 白底黑字       | 附加说明     |

核心记忆：

- 停车让行：八角形，"停"字
- 减速让行：倒三角形，"让"字
- 禁止驶入：红底白横杠
- 禁止通行：红底白圆圈
- 交叉路口预告标志：带有多条道路名称与多方向箭头的蓝底预告标牌
- 指路标志：标注道路名称、行驶方向、距离信息的蓝底道路标牌（与指示标志区分）
- 注意潮汐车道：黄底三角形、双向箭头搭配两侧虚线的警告标志

### 3.4 交通标线

| 标线                | 含义                                           |
| ------------------- | ---------------------------------------------- |
| 白色虚线            | 同向分隔，可跨越                               |
| 黄色虚线            | 对向分隔，可跨越                               |
| 白色实线            | 同向禁止跨越                                   |
| 黄色实线 / 双黄实线 | 对向禁止跨越                                   |
| 导流线              | 路口斜纹填充三角区域，禁止压线、越线行驶及停车 |
| 菱形标线            | 人行横道预告                                   |
| 黄色网格线          | 禁止停车（可通行）                             |
| 路缘石黄实线        | 禁止停车                                       |
| 路缘石黄虚线        | 允许临时停车                                   |

### 3.5 交警手势

| 手势       | 动作                   | 含义     |
| ---------- | ---------------------- | -------- |
| 停止       | 左臂向上直伸，手掌向前 | 停止     |
| 直行       | 双手平伸，手掌向前     | 直行     |
| 左转弯     | 右手向前平伸，左手摆动 | 左转弯   |
| 右转弯     | 左手向前平伸，右手摆动 | 右转弯   |
| 左转弯待转 | 左手向左下方摆动       | 待转     |
| 变道       | 右手水平摆动           | 变道     |
| 减速慢行   | 右手向下摆动           | 减速     |
| 靠边停车   | 左臂向上，右手向下摆动 | 靠边停车 |

## 四、驾驶证与准驾车型

**★★★★ · 约8%**

### 4.1 准驾车型代号

| 代号 | 车型           | 关键限制                   |
| ---- | -------------- | -------------------------- |
| A1   | 大型客车       | 22~63 周岁，只能增驾       |
| A2   | 重型牵引挂车   | 含 C6                      |
| A3   | 城市公交车     |                            |
| B1   | 中型客车       |                            |
| B2   | 大型货车       |                            |
| C1   | 小型汽车       | 含 C2/C3/C4，**不含 C6**   |
| C2   | 小型自动挡汽车 | 仅限自动挡                 |
| C6   | 轻型牵引挂车   | 只能增驾，需 C1/C2 满 1 年 |
| D    | 普通三轮摩托车 |                            |
| E    | 普通二轮摩托车 |                            |
| F    | 轻便摩托车     |                            |

### 4.2 C6 轻型牵引挂车

- 只能通过增驾取得，不得初次申领
- 需 C1/C2 驾照满 **1 年**，且本记分周期及前一个记分周期无满 12 分记录
- 增驾考试：科目二（桩考、曲线行驶、直角转弯）+ 科目三安全文明驾驶常识
- C1 不包含 C6，A2 可直接驾驶 C6
- 申请年龄：20~70 周岁（60~70 周岁需通过三力测试）

### 4.3 申领年龄限制

| 车型                                | 现行上限                                       |
| ----------------------------------- | ---------------------------------------------- |
| 大中型客货车申领                    | 63 周岁                                        |
| 大中型客货车驾驶                    | 63 周岁，可申请延期最长 3 年（需通过三力测试） |
| 低速载货汽车等                      | 63 周岁                                        |
| 普通三轮 / 二轮摩托车、轻型牵引挂车 | 70 周岁                                        |

### 4.4 70 周岁以上驾驶人

- 申领时需通过记忆力、判断力、反应力 **三力测试**
- 每年提交一次身体条件证明（身体条件证明自出具之日起 **6 个月内**有效）
- 可申请车型：C1、C2、C5、F
- 不得驾驶：低速载货汽车、三轮汽车、轻型牵引挂车、普通三轮摩托车、普通二轮摩托车

### 4.5 实习期

- 初次取得汽车类或摩托车类准驾车型后 **12 个月**为实习期
- 汽车类和摩托车类实习期分开计算，增驾同类无实习期
- 实习期上高速需持相应或更高准驾车型 **3 年以上**驾驶人陪同
- 实习期记满 12 分 → 注销实习准驾车型资格
- 实习期内不得参加学法减分
- 实习期内驾驶机动车牵引挂车，处 **20 元以上 200 元以下**罚款

### 4.6 换证与补证

- 遗失 / 损毁：核发地或核发地以外任一车管所均可补发
- 补领后原驾驶证作废，继续使用罚款 20~200 元
- 信息变更：30 日内向车管所备案
- 恢复驾驶资格考试跨省可办：逾期未换证被注销不满 2 年，全国任一地可申请

### 4.7 不得申请驾驶证的情形

- 提供虚假材料 → 500 元以下罚款，**1 年内**不得再次申领
- 欺骗、贿赂取得 → 2000 元以下罚款，**3 年内**不得再次申领
- 考试中贿赂 / 舞弊 → 取消资格，2000 元以下罚款，**1 年内**不得再次申领
- 组织作弊 → 3 年以下有期徒刑或拘役，并处或单处罚金；情节严重 3~7 年，并处罚金
- 3 年内有吸毒行为或代替他人考试行为
- 身体条件不适宜继续驾驶机动车仍然驾车行驶，处 **200 元以上 500 元以下**罚款

## 五、机动车登记与管理

**★★★ · 约 4%**

### 5.1 登记分类

注册登记 · 变更登记 · 转移登记 · 抵押登记 · 注销登记

### 5.2 注册登记

- 初次申领号牌 / 行驶证：向住所地车管所申请
- 需提交：身份证明、购车发票、交强险凭证、完税证明等
- 被查封 / 扣押期间不得办理
- 危险货物运输车登记所有人应为单位

### 5.3 变更登记

- 改变车身颜色 / 更换发动机 / 车身或车架 → 需申请变更登记
- 加装防撞装置 / 增加车内装饰 → 无需变更登记
- 未按时办理 → 警告或 200 元以下罚款

### 5.4 转移登记

- 所有权转让后，现所有人应自交付之日起 **30 日内**申请
- 抵押登记期间可办理转让（需三方共同申请）
- 未按时办理 → 警告或 200 元以下罚款
- 机动车办理转出过户，现车主不在车辆管理辖区的，转出地车管所自受理之日起 **3 日内**查验机动车

### 5.5 号牌管理

- 补发 / 换发号牌：受理后 **15 日内**发放，期间发临时号牌（有效期 15 日）
- 收到号牌之日起 3 日后，临时号牌作废
- 同一所有人名下两车号牌可申请互换（需无未处理违法记录）

### 5.6 检验

- 非营运小微型载客汽车（面包车除外），注册登记 10 年内，**第 6 年、第 10 年上线检验**，每 2 年申领检验合格标志；注册登记满 10 年以后，每年检验一次。

### 5.7 报废

- 达到报废标准 → 必须及时办理注销登记，不得上路
- 驾驶报废机动车上路 → 罚款 + 吊销驾驶证

## 六、驾驶人考试制度

**★★★ · 约 3%**

### 6.1 科目二考试内容

| 车型               | 项目                                                         |
| ------------------ | ------------------------------------------------------------ |
| C1（小型手动挡）   | 倒车入库、坡道定点停车和起步、侧方停车、曲线行驶、直角转弯（5 项） |
| C2（小型自动挡）   | 倒车入库、侧方停车、曲线行驶、直角转弯（4 项，*取消坡道定点*） |
| C6（轻型牵引挂车） | 桩考、曲线行驶、直角转弯                                     |

### 6.2 考试机会与期限

- 科目二和科目三分别有 **5 次**考试机会（非合计 5 次）
- 学习驾驶证明有效期 **3 年**（从科目一合格起算）
- 小型汽车异地分科目考试，变更次数不超过 **3 次**
- C2 科目三：科一通过后 20 日可预约；C1：30 日
- 科目三路考里程不少于 **3 公里**（C1、C2 小型汽车、小型自动挡汽车）
- 科目二 / 科目三满分 100 分，**90 分**合格

### 6.3 考试作弊处罚

- 考试中贿赂 / 舞弊 → 取消资格，已通过成绩无效，2000 元以下罚款，1 年内不得再次申领
- 组织作弊 → 3 年以下有期徒刑或拘役，并处或单处罚金；情节严重 3~7 年，并处罚金
- 代替他人考试 → 处拘役或管制并处罚金，驾驶证被注销
- 3 年内有替考行为 → 不得申请驾驶证

## 七、让行规则

**★★★★ · 约 8%**

```
右转让左转 → 左转让直行 → 转弯让直行
```

### 7.1 三大先行原则

1. 转弯让直行
2. 右方道路来车先行
3. 右转弯让左转弯

### 7.2 特殊让行

| 狭窄坡道   | 上坡先行；下坡已行至中途则下坡先行   |

| 环岛       | 准备进入的让已在路口内的先行         |
| 辅路       | 让主路先行                           |
| 人行横道   | 行人优先，停车让行                   |
| 有交警指挥 | 交警指挥优先于信号灯                 |

## 八、超车规则

**★★★★ · 约 5%**

### 8.1 基本要求

- 只能从 **左侧**超车
- 提前开启左转向灯
- 变换远近光灯或鸣喇叭示意

### 8.2 不得超车的情形

1. 前车正在左转弯、掉头、超车
2. 与对面来车有会车可能
3. 前车为执行紧急任务的警车、消防车、救护车、工程救险车
4. 行经：铁路道口、交叉路口、窄桥、弯道、陡坡、隧道、人行横道、市区交通流量大路段

### 8.3 超车后

- 拉开安全距离后，提前开右转向灯再驶回
- 超车时前车不让 → 放弃超车

## 十、高速公路规定

**★★★★★ · 约 8%**

### 10.1 进入 / 驶离

- 进入：匝道加速，开左转向灯，速度提到 60km/h 以上
- 驶离：提前开右转向灯，虚线处进入减速车道
- 不得压实线、导流线，不得连续变更车道

### 10.2 故障处理

```
开双闪 → 车靠边 → 人撤离 → 设警告 → 即报警
```

| 步骤 | 操作                              |
| ---- | --------------------------------- |
| 1    | 开启危险报警闪光灯                |
| 2    | 移至应急车道                      |
| 3    | 来车方向 **150 米外**设置警告标志 |
| 4    | 人员转移至护栏外                  |
| 5    | 报警                              |

- 无法正常行驶时，由救援车、清障车拖曳（不得擅自牵引）
- 普通道路故障：警告标志放车后 **50~100 米**

### 10.3 禁止行为

- 倒车、逆行、穿越中央分隔带掉头 → **记 12 分**
- 错过出口 → 继续前行至下一出口
- 高速公路 / 城市快速路违法停车 → **记 9 分**
- 长期骑轧车道分界线、频繁变更车道

## 十一、停车规定

**★★★★ · 约 12%**

### 11.1 禁停距离

```
站 30 · 口 50
```

| 范围                                                     | 距离          |
| -------------------------------------------------------- | ------------- |
| 公交站、急救站、加油站、消防栓 / 消防队门前              | **30 米**以内 |
| 交叉路口、铁路道口、急弯路、窄路 (<4m)、桥梁、陡坡、隧道 | **50 米**以内 |

### 11.2 绝对禁停

人行横道 · 黄色网格线 · 非机动车道 · 禁停标志 / 标线路段 · 施工地段 · 有隔离设施的路段

### 11.3 停车原则

- 不得妨碍其他车辆和行人
- 应在停车泊位内停放
- 临时停车需开危险报警闪光灯
- 按顺行方向，紧靠道路右侧
- 允许临时停车的路段应当顺向停车，车身右侧距离路缘不得超过 **30 厘米**

## 十八、伤员急救

**★★★ · 约 2%**

### 18.1 基本原则

- 先救命后治伤，优先抢救有生命危险的
- 昏迷伤员：先检查呼吸 → 开放气道 → 仰卧位
- 心肺复苏：胸外按压 ≥100 次/分，≤120 次/分
- 中毒伤员：第一时间转移到新鲜空气处
- 有害气体泄漏：抢救人员佩戴空气呼吸器或用湿毛巾捂口鼻

### 18.2 止血

- 先止血，再包扎
- 动脉出血 → 压住**近心端**
- 静脉出血 → 压住**远心端**
- 不能用麻绳包扎，可用毛巾、手帕等替代
- 失血休克 → 保暖措施

### 18.3 烧伤

- 全身燃烧 → 喷冷水灭火降温
- 烧伤口渴 → 喝少量**淡盐水**（不能只喝白开水）
- 水泡保护 → 塑料袋或保鲜膜覆盖
- 烫伤 → 常温清水持续冲洗

### 18.4 骨折

- 先止血包扎，再固定
- 固定范围超过伤口上下关节
- 脊柱骨折 → 三角巾固定，不能随意移动，不能用软担架
- 车辆着火 → 往**上风**方向撤离

## 十九、处罚与法律责任

### 19.2 肇事逃逸与交通肇事罪

**肇事逃逸记分与行政处罚**  
- 造成轻微伤或仅财产损失事故后逃逸，尚不构成犯罪 → **一次记 6 分**  
- 造成轻伤、重伤或死亡事故后逃逸，尚不构成犯罪 → **一次记 12 分**  
- 无论记 6 分还是 12 分，行政处罚统一：**200~2000 元罚款，可以并处 15 日以下拘留**；逃逸一般认定为全责。  
- 若逃逸行为构成犯罪（交通肇事罪），直接**吊销驾驶证，终生不得重新申领**，追究刑事责任，不再适用记分规则。

**交通肇事罪（《刑法》第133条，过失犯罪）**

三档法定刑：

**第一档：3 年以下有期徒刑或者拘役**（满足下列情形之一即构罪）  
- 死亡 1 人 / 重伤 3 人以上，负事故全部或主要责任  
- 死亡 3 人以上，负同等责任  
- 公私财产直接损失，全责或主责，无力赔偿 ≥30 万元  
- 致 1 人以上重伤，全责或主责，且具有酒驾、毒驾、无证驾驶、驾驶报废车辆、严重超载、肇事后逃逸六种情形之一  

**第二档：3 年以上 7 年以下有期徒刑**（两种情形）  
- 交通运输肇事后逃逸（已构成交通肇事罪，为逃避法律追究而逃跑）  
- 其他特别恶劣情节：死亡 2 人以上 / 重伤 5 人以上，全责或主责；或死亡 6 人以上，同等责任；或财产直接损失全责/主责无力赔偿 ≥60 万元  

**第三档：7 年以上有期徒刑**  
- 因逃逸致人死亡（肇事后逃逸，致使被害人因得不到救助而死亡）

速记口诀：  
```
假一吊二撤三醉五逃终生
（逃逸构成犯罪终生禁驾）
```

### 19.4 扣留车辆

```
两证两标一号牌，上路没有就扣车
```

- 两证：驾驶证、行驶证
- 两标：检验合格标志、保险标志
- 一号牌：机动车号牌

### 19.5 危险驾驶罪（《刑法》第133条之一）

在道路上驾驶机动车，有下列情形之一的，**处拘役（1个月以上6个月以下），并处罚金**：

1. 追逐竞驶，情节恶劣的  
2. 醉酒驾驶机动车（血液酒精含量 ≥80mg/100ml）  
3. 从事校车业务或者旅客运输，严重超过额定乘员载客，或者严重超过规定时速行驶的  
4. 违反危险化学品安全管理规定运输危险化学品，危及公共安全的  

> 无证驾驶不属于危险驾驶罪。

### 19.6 处罚种类

警告 · 罚款 · 暂扣 / 吊销驾驶证 · 拘留（共 4 种，不含训诫）

### 19.7 罚款缴纳与行政处罚

- 收到交通行政处罚决定书之后，需在 **15 日内**向指定银行缴纳罚款。

## 二十、安全行车常识

**★★★★ · 约 14%**

### 20.1 防御性驾驶

| 原则     | 要点               |
| -------- | ------------------ |
| 放眼远方 | 视线提前量 15 秒   |
| 环回视野 | 不断扫视周围       |
| 留有余地 | 保持安全距离和空间 |
| 引人注意 | 鸣笛、变换灯光     |
| 顾全大局 | 主动礼让           |

### 20.2 场景应对

| 场景              | 正确做法                                                     |
| ----------------- | ------------------------------------------------------------ |
| 遇行人横过道路    | 减速或停车让行                                               |
| 遇非机动车抢行    | 主动减速让行                                                 |
| 遇儿童            | 减速慢行，必要时停车                                         |
| 皮球滚到路上      | 减速，随时准备停车（可能有儿童）                             |
| 驶近公交车站      | 减速，留出横向距离，准备停车                                 |
| 遇强行超车 / 加塞 | 主动礼让，保持安全车距                                       |
| 前方道路堵塞      | 按顺序停车等候                                               |
| 山区弯道          | 减速、鸣号、靠右行                                           |
| 积水路面          | 减速慢行，避让行人                                           |
| 湿滑路面          | 发生跑偏时松开制动踏板，小幅调整方向，切勿持续踩刹车，防止车轮锁死加剧失控 |
| 夜间行车          | 多短促鸣笛，变换远近光灯                                     |
| 急转弯            | 充分减速，靠右行驶                                           |
| 倒车              | 遇过往车辆主动停车避让                                       |

### 20.3 驾驶操作规范

- 上车前：逆时针绕车一周检查
- 加速踏板：轻踏、缓抬
- 直线行驶：车速越快，转向盘操作越少越慢
- 下长坡：利用发动机制动（非连续踩刹车）
- 制动跑偏原因：左右车轮制动力分配不均匀
- 检查机油：车辆停平，发动机启动前，油尺在上下限之间

### 20.4 禁止驾驶行为

1. 车门 / 车厢未关好行车
2. 前后窗范围内悬挂 / 放置妨碍视线的物品
3. 拨打接听手持电话、观看电视等（记 3 分）
4. 下陡坡熄火或空挡滑行
5. 向道路上抛撒物品
6. 连续驾驶超 4 小时未停车休息或休息少于 20 分钟
7. 禁止鸣喇叭区域 / 路段鸣喇叭

### 20.5 不得驾驶的条件

饮酒后 · 服用精神药品 / 麻醉药品 · 患有妨碍安全驾驶的疾病 · 过度疲劳

## 二十一、智能驾驶

**★ · 约 1%**

### 21.1 汽车驾驶自动化分级（GB/T 40429-2021）

| 级别 | 名称           | 说明                         |
| ---- | -------------- | ---------------------------- |
| L0   | 应急辅助       | 无持续驾驶自动化             |
| L1   | 部分驾驶辅助   | 单一功能辅助（如定速巡航）   |
| L2   | 组合驾驶辅助   | 多项功能协同（如 ACC + LKA） |
| L3   | 有条件自动驾驶 | 特定条件下可自动驾驶         |
| L4   | 高度自动驾驶   | 限定场景完全自动驾驶         |
| L5   | 完全自动驾驶   | 任何场景完全自动驾驶         |

### 21.2 常见辅助驾驶功能

| 功能               | 说明                   | 注意事项               |
| ------------------ | ---------------------- | ---------------------- |
| 自适应巡航 (ACC)   | 自动保持车速和跟车距离 | 仍需驾驶员保持注意力   |
| 车道保持辅助 (LKA) | 帮助车辆保持在车道内   | 不能替代驾驶员控制方向 |
| 自动紧急制动 (AEB) | 检测碰撞风险自动刹车   | 有速度和场景限制       |
| 盲点监测 (BSD)     | 检测盲区车辆           | 变道前仍需回头确认     |

> 所有辅助驾驶功能仅为辅助，驾驶员始终是安全第一责任人。
